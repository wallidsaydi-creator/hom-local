# Security

For the full security documentation, see [docs/security.md](docs/security.md).

## Reporting vulnerabilities

If you discover a security vulnerability, please report it privately through the security contact listed in the repository. Do not disclose vulnerabilities in public issues.

## Sensitive data and licensing

Do not report secrets, private memory exports, private logs, credentials, or user data in public issues.

If a licensing, ownership, or private-data leak is discovered, report it privately through the security contact.
